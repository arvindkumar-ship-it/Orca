# Merge verification — what was actually tested

This is the FULL merged repo: WaveSafe (cloned from
github.com/arvindkumar-ship-it/WaveSafe) + the ORCA overlay, combined into
one tree and verified to actually import and build. Previous zips in this
session were an incomplete overlay-only diff; this one is the real thing.

## Verified this session (not just claimed)

1. **`pip install -r requirements.txt`** — succeeds (added `anthropic` for
   the agents package, which was missing).
2. **`python3 -m py_compile` on every `.py` file** — zero syntax errors.
3. **`python3 -c "import app.main"`** with dummy env vars — succeeds after
   fixing 5 real integration bugs found by actually running it (see below).
4. **62 real API routes** confirmed live via
   `TestClient(app).get("/openapi.json")` — every ORCA endpoint
   (`/v1/chat`, `/v1/zones/*`, `/v1/geofence/*`, `/v1/route/plan`,
   `/v1/ocean/*`, `/v1/safe-harbors/guidance`) registered alongside every
   COPY WaveSafe endpoint (auth, incidents, admin, tracking, etc).
5. **`npm install`** — succeeds (after fixing a real React 19 / react-leaflet
   v4 peer-dependency conflict — bumped to react-leaflet v5).
6. **`npm run build`** — succeeds, 111 modules, clean production bundle.

## Real bugs found and fixed by actually running this (not by re-reading code)

1. `app/models/__init__.py` imported `Beach`/`SafeZone`/`BeachForecast`/
   `HazardAlert`/etc. directly from `geospatial.py`/`forecast_risk.py` —
   broke the instant those files were overwritten with ORCA's versions.
   **Fix**: `_wavesafe.py` suffix copies of the originals, `__init__.py`
   updated to pull from both.
2. Several COPY files (`admin_service.py`, `trip_service.py`,
   `internal_service.py`, workers, `open_meteo_connector.py`) import
   `Beach`/`BeachForecast`/etc. **directly from the submodule path**
   (`from app.models.geospatial import Beach`), bypassing `__init__.py`
   entirely. **Fix**: re-export lines added inside ORCA's own
   `geospatial.py`/`forecast_risk.py` so both import paths keep working.
3. `app/services/ingestion_service.py` imports `IncoisConnector` by that
   exact class name; ORCA's generalized connector was renamed
   `IncoisPfzConnector`. **Fix**: backward-compat alias
   (`IncoisConnector = IncoisPfzConnector`) — correct here, not a hack,
   since this file's whole purpose in ORCA IS the PFZ connector now.
4. `zone_service.py` called `forecast_engine.engine.compute_forecast_outlook
   (zone_id, ...)` — but that function is beach-keyed all the way down to a
   raw `load_beach(session, beach_id)` call; passing a zone_id in would
   have silently queried the wrong table (a real, dangerous logic bug, not
   just an import error). **Fix**: new `forecast_engine/zone_engine.py`
   with a proper zone-keyed `compute_forecast_outlook`, reusing
   `outlook.py`'s `build_outlook`/`find_safe_windows` unchanged (those are
   genuinely beach/zone-agnostic — only the beach-coupled parts needed a
   zone sibling). `zone_service.py`'s import fixed to point at it.
5. `forecast_engine/outlook.py` (COPY, unchanged) imports `load_beach` from
   `risk_engine.data_loaders` at module level — broke when that file was
   overwritten with zone-only loaders. **Fix**: `data_loaders_wavesafe.py`
   (the original beach-keyed loaders, reconstructed faithfully) +
   re-export of `load_beach` into `data_loaders.py`.

## What is still NOT verified (stated plainly)

- **No real Postgres/PostGIS/Redis was available in this session** — every
  route's actual request-handling logic (DB queries, geometry functions,
  Redis pub/sub) has never executed. Import success and route registration
  are necessary but not sufficient for correctness — a wrong column name
  inside a route handler's SQL, for instance, would not be caught by
  anything done here.
- The `chat_sessions`/`voyage_watches`/etc. migrations (021-025) have never
  been run against a real database.
- No automated tests were written or run for any ORCA-specific logic
  (the A* optimizer, the risk scoring formula, the geofence queries).
- `frontend/package-lock.json` was regenerated by this session's
  `npm install` — different from whatever was in WaveSafe originally.
